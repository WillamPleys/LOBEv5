LOBE - Design Your Needs (v5)
================================

Nama database: "lobe_v5_db"
Nama user admin: "admin"
Password admin: "admin321"

Installation:
1. Ensure your MySQL server is running.
2. Run `php database_update/migrate.php` to install the database schema.
3. Access the application at `index.php`.

Features:
- Windows-like workspace interface.
- 16 Widgets including AI Assistant, Code Editor, and more.
- Admin Panel (`admin.php`) for managing Users, Transactions, and Products.
- Automatic Advertisements every 5 minutes.
